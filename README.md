I build practical web applications, APIs and self-hosted tools, from interactive frontends to database-backed services. I'm particularly interested in application architecture, simulation systems, automated testing and running software on Linux/VPS infrastructure.

## Selected projects

### [microJBase](https://github.com/jdwd40/microJBase) — Lightweight self-hosted backend
A small Node.js/TypeScript and PostgreSQL backend for authentication and controlled data access. Built around Fastify, revocable sessions, explicit table exposure, database row-level security, versioned migrations and automated tests.

**Explore:** [Source and documentation](https://github.com/jdwd40/microJBase)

### [Coins / Crypto Chaos](https://github.com/jdwd40/fcoins_y) — Persistent market simulation
A virtual-money cryptocurrency trading game with a continuously changing market, price history, events, a portfolio and leaderboards. React/TypeScript on the frontend; Node.js, Express and PostgreSQL on the backend.

**Explore:** [Live application](https://jdwd40.com/coins/) · [Frontend](https://github.com/jdwd40/fcoins_y) · [Backend](https://github.com/jdwd40/back_coins_x)

### FootFive / Proball Manager — Live football management simulation
A continuously running fictional football competition with teams, player management, match events and records. This is an actively developed application; its current application repository is private, while older public frontend/backend repositories are retained for reference.

**Explore:** [Live application](https://jdwd40.com/footfive/) · [Earlier backend implementation](https://github.com/jdwd40/footfive_back)

### [Study System](https://github.com/jdwd40/study-system) — Personal learning platform
A React/TypeScript study application with Git-managed curriculum content, SQLite-backed progress and review data, spaced-repetition flashcards and an integration with my personal AI-assistant workflow.

**Explore:** [Source and documentation](https://github.com/jdwd40/study-system)
